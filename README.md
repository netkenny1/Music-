# Midnight Transit — a house track written entirely in code

A club-ready house track, synthesised from scratch in Python. No samples, no
loops, no DAW, no third-party audio libraries. Every kick, hat, chord and
reverb tail in the finished master is generated by the DSP code in this repo.

```
Key     F minor
Tempo   124 BPM
Length  192 bars (6:11) -- a club edit, in 8/16/32-bar phrases
Form    32 intro / 32 groove / 16 breakdown / 16 build / 64 drop / 32 outro
Output  24-bit 48 kHz master, 16-bit 44.1 kHz, and MP3
```

## Run it

```bash
pip install numpy scipy
python3 engine/render.py --out output
```

Renders the full track and prints a mastering report. Output is deterministic —
every random process is seeded, so the same code always produces the identical
waveform.

```bash
python3 engine/render.py --bars 96-112     # 16 bars of the drop, for iterating
python3 engine/render.py --serial          # single-process mixing, for timing
```

A `--bars` window goes through the same sequencer, mixer and master chain as
the full track and is written with a `_bars96-112` suffix so it never overwrites
the master. Two honest caveats: loudness targeting only sees the window, so the
limiter drive can differ by a fraction of a dB, and anything that started
sustaining more than two bars before the window is not there.

Mixing runs the thirteen channel strips, then the four reverb buses, across
every core by default. The strips are independent until the sum, so the
parallel result is bit-identical to the serial one, not merely close --
verified with `np.array_equal` on the master output.

Measured on four cores: a full render went from 434 s to 196 s (2.2x). The
strips themselves went from ~290 s to ~75 s; what remains is sequencing and
the master chain (~70 s), both still single-process. The fuller 20-channel
arrangement then cost 232 s, and round-robin note pools for the texture, pads
and stabs (the drum cache's trick applied to synths) brought it back to 207 s
-- sequencing 35 s for ~2,500 notes, faster than the original 40 s for far
fewer. A stage
profile is what decided this -- instrument synthesis turned out to be under
10% of the total, so the on-disk instrument cache that seemed like the obvious
first move was never built.

## How it is built

Signal flow, top to bottom:

```
oscillators ─▶ filters ─▶ envelopes ─▶ instrument voices
                                            │
                                            ▼
                                      sequencer (patterns + harmony)
                                            │
                                            ▼
   channel strip:  HP/LP ─▶ filter automation ─▶ EQ ─▶ saturation
                        ─▶ compressor ─▶ sidechain duck ─▶ width/mono ─▶ fader
                                            │
                            ┌───────────────┼───────────────┐
                            ▼               ▼               ▼
                       room reverb    plate reverb     ping-pong delay
                        hall reverb            (shared sends)
                            └───────────────┼───────────────┘
                                            ▼
   master:  HPF ─▶ tone EQ ─▶ glue comp ─▶ M/S width ─▶ saturation ─▶ limiter
```

### `engine/dsp/` — the primitives

| File | What it does |
|---|---|
| `core.py` | Band-limited oscillators (PolyBLEP), noise, envelopes, panning |
| `filters.py` | RBJ biquad cookbook, 24 dB/oct cascades, swept filters, formants |
| `dynamics.py` | Compressor, sidechain ducking, oversampled saturation, limiter |
| `space.py` | Convolution reverb, delay, mid/side width, mono-maker, chorus |

### `engine/` — the music

| File | What it does |
|---|---|
| `instruments.py` | Synthesised voices: drums, bass, drawbar organ, stab, pad, electric piano, vocal, FX |
| `composition.py` | Tempo, key, chord progression, rhythm patterns, song structure |
| `groove.py` | Syncopation scoring and per-instrument micro-timing |
| `mixer.py` | Channel strips, effect sends, master chain, per-channel stem capture |
| `render.py` | Sequencer and entry point |
| `analysis.py` | LUFS / true-peak / correlation metering (ITU-R BS.1770-4) |

## The techniques that matter

**Band-limited oscillators.** A sawtooth generated naively as `2*phase - 1`
has harmonics above Nyquist that fold back down as inharmonic buzz. PolyBLEP
replaces each waveform discontinuity with a short polynomial transition that
cancels most of that foldback. This is the single biggest difference between
synthesis that sounds cheap and synthesis that sounds like a synth.

**The kick is a pitch envelope.** It sweeps from 168 Hz to 47 Hz in about
25 ms. The ear reads that fast downward glide as physical impact; hold the
pitch steady and you get a boop. Saturation then adds harmonics at 94, 141 and
188 Hz so the kick still reads on phone speakers that cannot reproduce 47 Hz —
the brain reconstructs the missing fundamental from the harmonic series.

**Sidechain ducking, drawn not detected.** The pump is generated directly from
the kick grid rather than by a compressor listening to the kick. That gives a
curve that is identical every bar, locked to the beat, with none of the
detector overshoot that smears the first few milliseconds.

**Convolution reverb with frequency-dependent decay.** Real rooms absorb treble
far faster than bass, so a hall stays warm as it fades. Each reverb impulse
response is built band by band with its own decay time. Left and right come
from independent noise so the tail is decorrelated and envelops the listener
instead of collapsing to the centre.

**Mono below 120 Hz.** Low frequencies carry most of a track's energy. If they
are out of phase between channels they partially cancel on a mono-summed club
subwoofer. The master collapses everything under 110 Hz to mono, and the bass
channel under 140 Hz.

**Oversampled saturation.** Distortion creates harmonics above the original
signal; at 48 kHz many land past Nyquist and alias back as dissonance. Every
waveshaper runs at 4× rate and filters on the way back down.

**Look-ahead limiting.** The gain curve is pushed backwards in time with a
running minimum, so the limiter is already turned down before a transient
arrives. Because the minimum's radius is wider than the smoothing radius, the
smoothing can never reintroduce an overshoot — no clipping stage is needed to
catch it.

## Why the first version sounded like an advert, and what changed

The first arrangement was *busy*. A 16th-note background pluck texture,
tambourine, congas, bells, a counter-melody, four hat patterns rotating every
two bars, an arpeggio, stutters, mini-drops, pushed claps, a polyrhythm, a
delayed drop. Every trick that keeps a thirty-second production-music cue
interesting -- and exactly what a club record does not do. Ad music is dense
and glossy and something new happens every bar. House is an 8-bar loop played
for six minutes, with about seven parts, where the interest is *phrasing*:
what enters and leaves on the 8-, 16- and 32-bar lines, and the fill that
announces each line. The listener is meant to lock in, not be entertained.

So the second version is built the way the genre actually is.

**The loop.** One bar of drums, two bars of chord riff, eight bars of harmony,
and nothing in it changes for the length of a section:

```
kick     X...x...x...x...    four on the floor -- the whole genre
clap     ....X.......X...    backbeat, 9 ms late
hat      Xo.oXo.oXo.oXo.o    16ths: accent on the kick, swung ghosts,
                             and NO closed hat where the open hat plays
ohat     ..x...x...x...x.    the off-beat 8th: the sound of house
shaker   o.xo.oxo.oxo.oxo    air
bass     ..x...x...x...x.    off-beat 8ths, legato through the kick
stab     ..X...x...X...x.    bar 1: off-beats
         ..X...x.x...X...    bar 2: third hit pulled a 16th early
```

The closed hat is *choked* out of the off-beat slot because a real hi-hat
cannot be open and closed at once -- programming it that way is what makes
the pattern read as a hi-hat rather than two noise generators.

**The bass is legato so the sidechain has something to grip.** Each off-beat
note holds until the next one, straight through the kick. The kick-locked
duck (depth 0.9, 30 ms hold, 180 ms release) pulls it 6-7 dB down for the
first 60 ms after every kick and has fully let go 30 ms before the off-beat
where the next bass note and the open hat land. The pad dips 8 dB on every
kick. That timing is the pump: the whole harmonic bed breathes in time with
the kick, deep enough to feel, released in time to never eat the off-beat.
A bass that only plays *between* kicks -- which is what an off-beat pattern
with short notes is -- has nothing for a sidechain to shape, and no amount of
duck depth makes it audible.

**The chords are an organ.** The stab is now a drawbar organ
(`instruments.organ()`: additive sines at the tonewheel harmonics, a 2nd/3rd
harmonic percussion click on the attack), with a quiet detuned-saw layer over
it for width. Sines have no upper partials to smear into the hats, which is
why organ chords sit in a house mix where supersaw chords fill every gap --
the supersaw stab of the first version was one of the things making it sound
like a trailer.

**Real bassline theory.** The bass plays the chord root; the last off-beat
before every chord change plays the *fifth of the chord that is coming*,
kept inside the bass register (`composition.approach_note()`). Fifth-to-root
is the strongest pull in tonal music -- it is what a dominant does -- and
disco and house bass players have used it as the standard turnaround for
fifty years. In the second half of every 8 bars the octave bounces on the
16th after beat 3 (`bass_bounce`), the "bouncing" house bassline.

**Phrasing is the form.** Every part enters or leaves on a phrase boundary.
The last bar of every 8 gets a clap roll on beat 4; the last bar of every
16 gets a bigger roll over beats 3-4 with the kick's fourth beat removed;
the last bar of every section swells a reversed cymbal into a crash on the
next downbeat. A DJ counts in phrases and a crowd hears in phrases; an
element arriving on bar 13 reads as a mistake, and a phrase ending without
a fill reads as a loop.

**Syncopation, scored.** `groove.py` implements the Longuet-Higgins & Lee
(1984) index: every position in the bar carries a metrical weight, and a
syncopation is counted whenever a rest at a strong position follows a note
at a weaker one. The kit measures **0** -- correct for four-on-the-floor,
where every position is articulated. The bass and stab measure **7** in the
riff's first bar (off-beat 8ths held through the beat) and **4** in the
second, where the early hit resolves onto the next downbeat. That is the
medium syncopation Witek et al. (2014) found peaks the urge to move: the
kit is square and the syncopation lives in the tuned parts.

**Micro-timing is not swing.** Swing (14 % of a 16th, an MPC 57 %) displaces
every odd 16th by a fixed fraction and is what the hat ghosts shuffle on.
Micro-timing is a per-instrument offset in milliseconds: the kick pinned at
0.0 ms as the reference, the bass 4 ms ahead so it pulls the groove forward,
the clap 9 ms behind so the backbeat sits back, the open hat 5 ms late.

## Measuring the mix, then fixing it at source

The first master measured fine on a loudness meter and still sounded dark and
boxy. A third-octave sweep of the main drop against a pink reference said why:
a **7-15 dB scoop from 160 Hz to 8 kHz**, worst in the 3-5 kHz presence band,
with a resonant bump at 500-630 Hz sitting inside it. A meter cannot show that;
only a spectrum can.

Master EQ would have been lipstick, so the mixer gained `keep_stems=` and every
channel was measured on its own. Three things fell out that no amount of
listening had made obvious:

* **The presence band contained no music.** Above 2.5 kHz the band leaders were
  clap, shaker and hats -- noise. The pad produced nothing above 2.5 kHz and the
  stab nothing above 4 kHz, because their filters closed to under a third of the
  cutoff for most of every note. The master was already boosting +3.2 dB at 4 kHz
  and +4 dB at 8.5 kHz and the result was *still* 15 dB under pink: it was
  amplifying hiss to chase harmonics the source never had.
* **Four melodic voices peaked in the same band.** arp, melody, rim and vox all
  had their energy maximum at 400-630 Hz. That is the bump, and it is mutual
  masking.
* **The 250 Hz master cut was deepening a hole.** It was there to "clear mud";
  the low-mids were already 7 dB below pink.

**The exciter.** Opening a lowpass only reveals harmonics an oscillator already
produced. To *create* presence, `dynamics.exciter()` band-passes the region that
still has energy (roughly 0.8-3 kHz), saturates it so a 1.2 kHz partial breeds
new ones at 2.4 and 3.6 kHz, high-passes the result so only the new harmonics
survive, and blends. Two details decide whether it works at all:

1. The band is normalised into the waveshaper. `tanh(0.02)` is 0.02 to four
   places -- an isolated 1-3 kHz slice of a mix is always quiet, so without
   normalisation the shaper is linear and generates nothing whatever the drive.
2. It is tuned from a *real* note, not a synthetic one. The first pass measured
   +13 dB on a lowpassed test saw and then +1.6 dB on an actual stab, because
   the real stab already had content at -50 dB up there and the test source had
   none. Drive 4.8 / mix 1.4 gives +9.8 dB on the real note with the peak level
   moving 0.4 dB.

**Slotting.** Each melodic voice was given its own band: rim and arp high-passed
up out of the pile, the melody given a 1.4 kHz peak, the vox boost moved from
3 kHz (where it had nothing to lift) to 1.8 kHz. The stab's sustain floor went
from 0.30 to 0.52 of cutoff so the chord keeps its body instead of closing to a
mumble after the transient.

**Measured on the main drop, relative to pink, anchored on the kick
fundamental:**

| band | before | after | change |
|---|---|---|---|
| sub 20-63 | +1.1 | +1.1 | 0.0 |
| bass 63-160 | +5.1 | +5.3 | +0.1 |
| low-mid 160-400 | -2.8 | -0.6 | **+2.2** |
| mid 400-1000 | -2.6 | -2.3 | +0.3 |
| upper-mid 1-3.15k | -6.7 | -5.3 | **+1.5** |
| presence 3.15-8k | -9.8 | -6.5 | **+3.3** |
| 500-630 Hz bump | +4.4 | +2.9 | **-1.5** |

The low end did not move, which is the point: everything was fixed above it,
at source, and the limiter is doing slightly less work than before (glue comp
-1.5 dB; the final master sits at 5.0 LU).

These measurements were made on the first, busier arrangement; the exciter,
the slotting and the stem capture all carried over to the club edit.

**Reference matching.** The last pass compares the drop's third-octave
spectrum against the tilt a commercial house master sits on: bass slightly
above the 80-125 Hz anchor, about -3 dB per octave from 100 Hz to 1 kHz,
about -4.5 dB per octave above that. The first measurement of the club edit
was 4.2 dB RMS off that curve, in two specific places: 3-6 dB light at
125-200 Hz, where warmth lives, and 5-11 dB hot from 8 to 16 kHz, which is
hat and shaker fizz. Both were leftovers of the earlier "too dark" fix --
high-passes at 150-170 Hz on the organ and pad that were cutting the
organ's 16' drawbar, and top-shelf boosts on the master and hat channels
that no longer had anything to rescue. Fixed at source first (organ
high-pass 150 -> 100 Hz, pad and stab high-passes lowered, hat shelves
removed, shaker -2 dB, the organ's 4th-6th drawbars pulled further out for
the empty 1.6-2 kHz band), then the master tilted for the remainder.

| band | before | after |
|---|---|---|
| 125-500 Hz, mean error | -2.8 dB | -1.1 dB |
| 1-4 kHz, mean error | -1.0 dB | -0.6 dB |
| 6.3-16 kHz, mean error | **+7.3 dB** | +0.1 dB |
| RMS error, 63 Hz-16 kHz | 4.2 dB | **1.4 dB** |

1.4 dB is inside the spread between real house masters, so the pass stops
there rather than chasing the reference into the noise.

## Arrangement

| Time | Bar | Section | Bars | What happens |
|---|---|---|---|---|
| 0:00 | 0 | intro | 32 | DJ intro. Kick + 8th hats; open hat and clap at 8; bass at 16; organ riff at 24 |
| 1:02 | 32 | main_a | 32 | The groove. Pad from bar 40, vocal hook from 48. Fills at 39, 47, 55, 63 |
| 2:04 | 64 | break | 16 | Drums out. Pad, electric piano, vocal. Nothing to dance to, on purpose |
| 2:35 | 80 | build | 16 | Kick back. Bass leaves at 88, riser, snare roll, kick to 8ths, last beat cut |
| 3:06 | 96 | drop | 32 | The drop: crash, sub drop, full groove, bounce bass |
| 4:08 | 128 | drop_b | 32 | Electric-piano riff 128-143; thinned to kick/bass/pad 144-151; all back 152 |
| 5:10 | 160 | outro | 32 | DJ outro. Organ and pad out at 168, bass at 176, clap and open hat at 184, filter closing |

The 32-bar beat-only intro and outro are the DJ's: unambiguous kick with no
melodic content to clash against the outgoing record, long enough to mix
across a full phrase.

### What is in the loop

| Element | What it does |
|---|---|
| **Kick** | Pitch-swept sine, 168 -> 47 Hz in 25 ms, saturated. Never micro-shifted, never varied |
| **Clap** | Four bursts 9-11 ms apart plus a room tail, on 2 and 4, 9 ms late |
| **Closed hat** | 16ths with the ghosts swung, choked out of the off-beat slot |
| **Open hat** | Every off-beat 8th, the pendulum against the kick |
| **Bass** | Filtered saws over a sine, off-beat 8ths, legato, sidechained 0.92; fifth-approach into each chord; octave bounce in the second half of every 8 |
| **Sub** | Pure sine under the bass roots, also sidechained, mono |
| **Organ stab** | Drawbar organ, two-bar riff, one chord per two bars; detuned-saw layer at -10 dB for width |
| **Pad** | Supersaw, one long note per chord, sidechained 0.95 -- the audible pump |
| **Electric piano** | Breakdown chords, and the tresillo riff (`x..x..x.`) in the second half of the drop |
| **Vocal** | Two syllables every four bars on the chord's top note, formant-filtered, through the hall |
| **FX** | Crash on every 32, reversed cymbal into every section, riser and snare roll in the build, sub drop on the drop |

## Harmony

`Fm9 → Dbmaj7 → Abmaj7 → Ebadd9` (i – VI – III – VII), two bars each.

Voiced so that every part moves by a tone or less:

```
Ab3  Ab3  G3   Bb3
C4   C4   C4   Eb4
Eb4  Db4  Eb4  F4
G4   F4   G4   Bb4
```

That smooth voice leading is why the loop feels like it circles rather than
restarts.

## Measured output

The master is judged by meters, not by hope. `engine/analysis.py` implements
ITU-R BS.1770-4 loudness, true-peak detection and stereo correlation, and
`engine/inspect_master.py FILE` prints a full report for any rendered WAV.

| Metric | Value | Why it matters |
|---|---|---|
| Integrated loudness | −10.6 LUFS | Club level, deliberately not pushed to the −9 the limiter could reach: at that point it was saturated and flattening the kick |
| Loudness range | 6.9 LU | Real contrast: the breakdown sits at −18 LUFS, the drop at −9.3 |
| True peak | ≈ −1.0 dBTP | Survives MP3 encoding without clipping |
| Crest factor | 11.0 dB | Loud but not squashed flat |
| Bass correlation | 1.00 | Low end is perfectly mono — no cancellation on a club sub |
| High correlation | 0.46 | Wide stereo image above 300 Hz |
| Mono sum delta | −0.2 dB | Almost nothing lost when summed to mono |

The true-peak number is the one worth explaining. An early render measured
−0.90 dBFS by sample peak but **+0.82 dBTP** — the waveform *between* samples
exceeded full scale, which an MP3 decoder reconstructs and clips. The limiter
now detects on a 4× oversampled copy, and the delivered MP3 decodes at
−0.1 dBTP with zero clipped samples.

## Validation

```bash
python3 engine/tests.py
```

44 checks covering the properties the mix depends on: that PolyBLEP actually
suppresses aliasing, that the limiter never exceeds its ceiling and is exactly
transparent below it, that filters attenuate where they claim to, that
oversampling removes distortion aliasing, that the mono-maker centres the low
end, and that the loudness meter matches the reference values published in
ITU-R BS.1770.
